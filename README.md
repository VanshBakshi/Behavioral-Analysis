# Behavioral Analysis AI

Advanced defensive User and Entity Behavior Analytics (UEBA).

## Stack
Python, PyTorch, Scikit-learn, Pandas, NumPy, FastAPI.

## Run
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python train.py
python app.py
```
Then open http://127.0.0.1:8000

The training data is synthetic. Use only authorized telemetry in real deployments.
